How it works
01
Sourced research first

Before this tool is used, a PMM builds a sourced product brief using Perplexity Deep Research — drawing from public product pages, Help Center docs, webinars, and customer stories. That brief becomes the source of truth.

02
Structured inputs, not a chat prompt

This form captures feature, persona, launch stage, and goals as structured inputs. The result is a consistent, repeatable prompt — not a one-off chat — so every run produces the same output shape.

03
Claude as the execution layer

Claude generates five standard outputs in one run. It's instructed to stay within the brief, label what's confirmed vs. interpreted, and flag missing information rather than invent it.

04
PMM reviews, refines, distributes

The output is a structured first pass — not a finished asset. PMM judgment, stakeholder alignment, and brand voice refinement are still essential. This tool compresses the setup work, not the thinking.
